# Progress sheet layout

Create a spreadsheet named **ExamMind — [Course name]** with these tabs.

## Tab 1: Course

| Field            | Value                    |
|------------------|--------------------------|
| Course           | e.g. Organic Chemistry 2 |
| Exam date        | YYYY-MM-DD               |
| Exam format      | e.g. MCQ + calculations  |
| Hours per day    | e.g. 2                   |
| Readiness        | formula: weighted average of mastery (high-yield counts double) |

## Tab 2: Topics

| Topic | High-yield | Mastery (0–100) | Level | Last practised | Next review | Common mistakes |
|-------|------------|-----------------|-------|----------------|-------------|-----------------|

- **Level** can be a formula from Mastery: <30 Weak, <60 Developing, <85 Strong, else Mastered.

## Tab 3: Sessions

| Date | Topics | Questions | Correct | % correct | Notes |
|------|--------|-----------|---------|-----------|-------|

- **% correct** = Correct / Questions.

## Tab 4: Plan

| Date | Topics | Type (learn / practise / review / mock) | Minutes | Done |
|------|--------|------------------------------------------|---------|------|
