# Progress sheet layout

Create one spreadsheet named **ExamMind** that covers all the student's courses, with these tabs.

## Tab 1: Courses

| Course | Exam date | Days left | Format | Length (min) | Total marks | Readiness % | Status |
|--------|-----------|-----------|--------|--------------|-------------|-------------|--------|

- **Days left** = exam date − today.
- **Status:** active / done.
- Under the table, add **Hours per day** and **Calibration** (share of "certain" answers that were correct).

## Tab 2: Topics

| Course | Topic | High-yield | Mastery (0–100) | Level | Blind spot | Last practised | Next review | Open mistakes |
|--------|-------|------------|-----------------|-------|------------|----------------|-------------|---------------|

- **Level** can be a formula from Mastery: <30 Weak, <60 Developing, <85 Strong, else Mastered (but not Mastered while Blind spot = yes).
- **Open mistakes** can be a count from the Mistakes tab.

## Tab 3: Mistakes

| Date | Course | Topic | Question (short) | Student answer | Correct answer | Why it was wrong | Confidence (1–3) | Status (open/fixed) | Fixed on |
|------|--------|-------|------------------|----------------|----------------|------------------|------------------|---------------------|----------|

## Tab 4: Sessions

| Date | Course | Mode (practice / review / flashcards / teach-back / mock) | Topics | Questions | Correct | % correct | Notes |
|------|--------|-----------------------------------------------------------|--------|-----------|---------|-----------|-------|

- **% correct** = Correct / Questions.
- For mock exams, put the score and timing notes in Notes.

## Tab 5: Plan

| Date | Course | Topics | Type (learn / practise / review / mistakes / mock) | Minutes | Done |
|------|--------|--------|----------------------------------------------------|---------|------|
