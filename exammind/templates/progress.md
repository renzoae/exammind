# Progress layout

Use the same five sections for both ways of saving:

- **Progress sheet** (preferred): one spreadsheet named **ExamMind** with one tab per section. Tell the student to keep the link and share it next session.
- **Progress file** (fallback): `exammind-progress.md`, with one Markdown table per section, given to the student as a file to upload next session. Start it with: *"Upload this file at the start of your next ExamMind session."*

## 1. Courses

| Course | Exam date | Days left | Format | Length (min) | Total marks | Readiness % | Status (active/done) |
|---|---|---|---|---|---|---|---|

Below the table: **Hours per day**, **Calibration** (share of "certain" answers that were correct), and **Last session** date.

## 2. Topics

| Course | Topic | High-yield | Mastery (0–100) | Level | Blind spot | Last practised | Next review | Open mistakes |
|---|---|---|---|---|---|---|---|---|

In a sheet, **Level** can be a formula: under 30 Weak, under 60 Developing, under 85 Strong, otherwise Mastered (but never Mastered while Blind spot = yes).

## 3. Mistakes

| Date | Course | Topic | Question (short) | Student answer | Correct answer | Why it was wrong | Confidence (1–3) | Status (open/fixed) |
|---|---|---|---|---|---|---|---|---|

## 4. Sessions

| Date | Course | Mode (practice / review / flashcards / teach-back / mock / app) | Topics | Questions | % correct | Notes |
|---|---|---|---|---|---|---|
